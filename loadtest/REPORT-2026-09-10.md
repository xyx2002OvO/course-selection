# 选课系统压测报告

日期：2026-09-11  
对象：本机 Docker 固定 cgroup 配额下的选课复刻（Gateway → Web → Dubbo → Redis Lua 受理 → Kafka → Worker `confirm()` 落库）  
身份：`X-Student-Id`，无登录  

**总评：M+**（本机配额结果，不能外推成生产集群 QPS，更不是 5000）

异步是削峰缓冲，不是加速器。500 QPS 指分散选课下的 **HTTP 受理（202）**。同窗口落库 **453**，不是 500 选课完成。

## 口径

| 说法 | 数字 | 不能写成 |
| --- | --- | --- |
| 500 QPS | hold-500 受理 **500 QPS**（202 成功率 99.87%） | 500 QPS 选课完成 |
| 压力下落库 | 同窗口 SUCCESS **453 QPS** | 和受理同一个数 |
| 400 | 落库 **369**、oldest **1s** | 400 已经完整贴住 |
| 窗口末积压 | pending **1744**，oldest **4s** | 已经排完 |
| HTTP 延迟 | 成功请求 p95 **77ms**，全程 p95 **79ms** | 异步比同步快 74% |

台阶吞吐以 `pipeline/database.csv` 对齐 k6 `setup_data.start`（毫秒 / 1000）为准。

## 实验预算

| 角色 | CPU | 内存 | 进程内限制 |
| --- | --- | --- | --- |
| API | 2.0 | 1Gi | 堆 512m，`ActiveProcessorCount=2` |
| Admission | 2.0 | 1Gi | Lua + `accept()` 写库；不消费 Kafka |
| Worker | 2.0 | 1Gi | Outbox + `confirm()`；`CONFIRM_CONCURRENCY=12` |
| MySQL | 4.0 | 2Gi | buffer pool 512M，`max-connections=80`，`innodb_flush_log_at_trx_commit=2`（与生产一致） |
| Redis | 1.0 | 256Mi | `maxmemory 128mb`，`noeviction` |
| Kafka | 1.0 | 768Mi | 堆 256m |
| k6 | 4.0 | 2Gi | 容器内打 `http://api:18080` |

合计约 **14 CPU / 6.5Gi**。Sentinel 每课 50 QPS；课程 211–230，500 全局时每课约 25。

## 主实验：`20260911-125350-ladder-confirm12`

学生 `20001–80000`，课程 `211–230`，每人新幂等键，只打受理。预热 20s@50，100/200/300/400 各 8s 爬升 + 20s hold，再 10s 爬到 500 并 hold 30s。`SUBMIT_GLOBAL=100000`。

| 台阶 | 目标 rps | 受理 QPS | 落库 QPS | 窗口末 pending | oldest | 判定 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| hold-100 | 100 | 100.3 | 100.5 | 3 | 0s | 跟上 |
| hold-200 | 200 | 200.0 | 200.0 | 10 | 0s | 跟上 |
| hold-300 | 300 | 300.2 | 288.3 | 268 | 2s | 基本跟上 |
| hold-400 | 400 | 400.2 | **368.9** | 619 | **1s** | 接近跟上 |
| hold-500 | 500 | **499.9** | **453.2** | **1744** | **4s** | 受理达标，落库 453 |

k6 47098 次，202/200 **47035**（99.87%），超时 63。成功请求 p95 **77ms**，全程 p95 **79ms**。停压 SUCCESS 47081 / ACCEPTED 17，基本排完。

## 正确性：`20260911-135752-correctness-confirm12`

课程 202 容量 50：`remaining=0`，`enrolled=50`，**drift=0**，SUCCESS 恰好 50。开放课 211–230 全部 **drift=0**。5xx=0。

正确性 **E** 要的是：500 主阶梯停压当场对 MySQL remaining / enrollment / Redis stock。`125350` 未跑 `stock-check`，故为 **M+**。

## 分面评级

| 面 | 评级 | 依据 |
| --- | --- | --- |
| 受理 | **M+** | hold-500 约 500 QPS，202 成功率 99.87%。 |
| 落库 | **M+** | 同窗口 453，oldest 4s，停压基本排完。不是 500。 |
| 正确性 | **M+** | 稀缺课 50/50、开放课 drift=0。主阶梯未当场对账，不上 E。 |
